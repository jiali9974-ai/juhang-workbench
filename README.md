# 巨航剪辑工作台

把门店口播原始素材自动剪成参考风格的抖音竖屏短视频（1440×2560 / 60fps）：
保留素材原声、字幕对应原话，支持去口误和长停顿、特写自动放大、美颜调色和人像封面。
粤语素材写粤语字幕，普通话素材写普通话字幕。

## 使用

AutoDL 素材剪辑服务器使用 `deploy/autodl/`，每 30 秒检查 GitHub `main`，支持 GPU 识别、素材剪辑出片、开机启动和更新失败回退。
云端部署自动跟随 GitHub `main`；详细机制、状态和回退方法见
[`deploy/README.md`](deploy/README.md)。本地未提交、未推送的修改不会同步到云端。

1. 第一次用：复制 `secrets.example.yaml` 为 `secrets.yaml`，填大模型 API Key（默认走 GPT 中转站，地址和模型在 `config.yaml` 的 `llm`）。
2. 双击 `start.bat`，浏览器打开 http://127.0.0.1:8765
3. 左边选拍摄批次（素材目录下按日期分的文件夹）→「一键识别并出脚本」。
4. 脚本出来后逐条「审核」：改字幕、删句子、调顺序 →「确认并出片」。
5. 成片在 `data/outputs/<批次>/`，网页里也能直接播放和下载。

## 画面编辑

底部「画面编辑」（原「美颜设置」）提供三类设置：

- **画面调整**：保留磨皮、提亮、统一光线和手表特写锐化。
- **文字与字幕**：调整实际口播字幕的字体、字号、颜色、描边和位置；添加自定义文字，修改内容、换行、拖动位置、复制、排序或删除。字体库内置 3 款字体，也可以上传 TTF / OTF（最大 25 MB），删除不再使用的用户字体。
- **动画标识**：引导箭头、重点圈选、点赞爱心、亮点闪光、认证对勾和好价标签。支持静止、淡入、弹入、呼吸缩放、上下跳动和摇摆，可调整颜色、大小、旋转、开始与结束时间。

预览画面可以直接拖动元素，用方向键微调；播放动画或拖动时间轴检查显示时间。「生成前 6 秒预览」会使用与正式出片相同的字体和 ASS 渲染逻辑生成实际 MP4。口播字幕在编辑页面使用示例文案，正式出片使用脚本中的字幕。

设置保存到 `data/settings/graphics.json` 和 `data/settings/look.json`，用于之后的单条与批量出片。更新已有成片时选择对应项目，点击「保存并重新出片」。用户字体保存在 `data/fonts/`，和生成数据一起留在本机，不进入 Git。

## 剪辑流程

| 步骤 | 模块 | 说明 |
|---|---|---|
| 识别 | `jh/asr.py` | VAD 切段 + SenseVoice，标出每句是粤语还是普通话，带逐字时间戳 |
| 出脚本 | `jh/script.py` + `jh/llm.py` | 大模型（GPT）按「开头钩子 → 逐只表讲解 → 结尾引导」选句，按原话语种写字幕 |
| 审核 | `web/index.html` | 人工确认，未确认的脚本不会出片 |
| 出片 | `jh/render.py` | 逐段裁切放大 → 拼接 → 烧字幕角标 → 响度统一 → 背景音乐闪避 |

剪辑时间规则在编码前统一处理（`jh/render.py` / `jh/speech_timing.py`）：片头开口前留 0.02 秒，普通切点在开口前、说完后各留 0.05 秒，成片最后一个字后留 0.2 秒。以实际出片人声音轨检测停顿，超过 1 秒无人声时同步裁掉中间音画，保留断点前后各 0.05 秒，并同步移动原声音轨起点、字幕时间；恰好 1 秒的停顿保留。参数在 `render.segment_gap` 和 `render.silence_cut`，背景音乐在裁剪之后再混入。

## 一键直接出片

素材和成片都不限制最短或最长时长，按内容完整、连贯、不重复来选句；短素材也可独立出片，不为凑秒数重复或编造内容。

批次页「一键直接出片」：识别 → 大模型出脚本 → 全部出片，中间不停下来审核。出完的片子仍然可以进「审核」改字幕、删句后重新出片。

## 智能体（大模型）

写剪辑脚本走 `jh/llm.py`：OpenAI 兼容接口，默认 GPT 中转站（`config.yaml` → `llm`）。
- 主模型 `gpt-6.1-sol`，失败时依次换 `fallback_models`（gpt-6、gpt-5.6）；502/429/超时自动重试。
- 这个中转站不支持 `response_format` 参数（带了会 502），所以 `json_response_format: false`，靠提示词要求只输出 JSON。
- 换回 DeepSeek：`base_url` 改 `https://api.deepseek.com`，`model` 改 `deepseek-chat`，`api_key_env` 改 `JH_DEEPSEEK_API_KEY`。

## 流程图和换模型

底部导航最右边的「流程图」展示「剪辑成片」每一步和使用的模型。
点开一步就能换模型（识别模型和运行设备、大模型主模型和备用模型、视频编码器），
大模型可以一键「测试」能不能用。改动直接写回 `config.yaml` 对应那一行（注释不动），下一次生成生效；
识别模型要在没有任务在跑时才能换。接口在 `jh/pipeline.py`。

## 配置

都在 `config.yaml`：素材路径、字幕字号位置、角标文字、放大倍数、背景音乐等。

## 前端

成片集中保存到 `D:\巨航\outputs`（`config.yaml` 的 `paths.output_root`）。成片库直接扫描该目录及项目子目录中的 MP4，目录为空时显示「暂无成片」。旧的 `data/outputs` 可作为指向成片目录的兼容链接。

「一键导出」压缩包中的视频使用成片卡片底部的标题命名，按项目分文件夹；同一目录中重名时自动追加 `(2)`、`(3)`，文件名不支持的字符会替换为下划线。

批量生成时，每完成一条就加入成片库；生成期间列表每 1.5 秒刷新，返回页面也会立即刷新。正在生成或重新生成的文件不展示。若旧服务仍在执行任务、尚无成片库接口，前端兼容读取项目脚本中已经出片且文件存在的条目，无需重启正在运行的任务。

项目页左侧列表下方可直接拖入视频或文件夹；每次上传会新建一个项目，上传完成后点「开始生成」。

上传失败的队列项可点「重试」，也可批量「重试失败项」；保留原文件、原项目和同一上传编号。
服务端会校验文件大小，同一上传编号重复提交不会生成重复素材。刷新浏览器后需要重新选择文件时，
在原项目点「补传素材」即可继续添加，不会新建项目。

封面人像抠图只使用 BiRefNet-portrait，MediaPipe 用于人脸表情、视线和身体、手部定位，不承担抠图。

封面选帧优先「看向镜头、闭嘴且不露齿的自然微笑」：使用离线 Face Landmarker 的表情、虹膜和头部姿态信息，同时检查睁眼、嘴唇闭合、口腔亮区、清晰度及构图。先在已剪辑片段里按真实帧时间抽样；微笑帧不足时搜索同一素材未剪入成片的部分，并在候选瞬间附近加密抽帧，优先稳定表情。模型文件和 Apache-2.0 许可随源码分发，来源和校验值见 `assets/face-landmarker-source.json`。

没有合适的闭嘴微笑时，选择看镜头、不露齿的自然表情，并在成片卡片显示原因。没有任何看镜头且自然的合格帧时明确报错，不再随意选第一帧或「问题最少」的侧脸。高清取帧、抠图通过后才生成封面，检查过程保存在 `data/renders/<项目>/<成片>/cover_check.json`。成功出片后将 `<编号>_封面选择.json` 与视频一起发布，取消重生成会保留旧成片和旧封面说明。
主抠图模型缺少权重、GPU 不可用或加载失败时，会停止出片并提示原因。

美颜页可选择成片，并用「更新成片」刷新列表。测试图使用封面选中帧的未美颜、未抠图原图；新成片会在 `outputs/<项目>/` 同时保存 `<编号>_封面原图.jpg` 和光线校正记录，之后不再依赖原素材。旧成片会尝试按 `cover_check.json` 补存原图；无法恢复时使用默认测试图并在页面提示。

默认测试图是「背书_01」封面选中的原始人像，保存在 `assets/beauty-default.jpg`，即使没有项目或成片也可调整、对比美颜效果。

美颜默认开启并统一光线，磨皮、提亮调色、手表特写锐化的默认值均为 50；「恢复默认」也使用这组数值。提亮只调整亮度通道，不再叠加增红、减绿或饱和度，保留自然肤色和中性白，并保护高光。预览、封面和重新出片共用这套滤镜；已有成片需重新出片才会应用。

默认图同时打包进前端，等待计算或接口报错时仍显示原图。运行中的旧服务可执行 `python -c "from jh import look_sources; look_sources.install_legacy_default()"` 安装默认预览缓存；图片保存在工作数据中，不创建素材项目。旧接口的对比图由浏览器保留，切换页面、调回之前的参数后仍能查看。

删除项目或成片会直接删除对应文件，不保留恢复副本。

上传队列、预览和导出请求以及任务进度由应用统一维护，切换页面后继续执行；返回时恢复上传进度、任务忙碌状态和预览结果。导航各页面时，全局任务栏会持续显示正在运行的任务。

React + Vite + Tailwind + shadcn/ui（Radix 版，和 21st.dev 的组件兼容），源码在 `frontend/`。
`start.bat` 用的是打包好的 `frontend/dist`，改了前端要重新打包：

```
cd frontend
npm run build      # 打包，工作台刷新即可看到
npm run dev        # 开发模式，http://localhost:5173，接口自动转发到 8765
```

加 21st 组件：在 21st.dev 登录后点组件的「Copy prompt」，把提示词交给 Claude Code 装进 `frontend/`。

## 取消上传与任务

上传列表可逐条「取消」或「取消全部上传」，也可从右下角任务栏取消上传。取消后保留「已取消」记录，已上传成功的素材不受影响。

右下角任务栏和剪辑流程页可取消排队、执行中的识别、脚本、出片和本地导入任务。排队任务直接跳过；执行中的任务显示「正在取消」，FFmpeg 会中断，模型推理在当前调用返回后停止，不再继续后续步骤。取消后的任务不会被当成失败弹窗，也不会阻塞后续任务。已完成的成片保留；取消重新生成时保留原成片，不发布半成品。新增后台取消接口后，需要在本地任务空闲时重启工作台才能生效。

## 按上传文件夹区分素材与成片

首页和素材页每次选择、拖入文件夹都会新建独立素材项目；同一次拖入多个文件夹时，每个顶层文件夹单独建项目，子文件夹仍归属对应根目录。再次上传同名文件夹会自动加 `_2`、`_3` 等编号，上传过程中可继续添加其他文件夹；上传、重试与取消始终保留原项目归属。选择一批散装视频则作为一次独立项目上传。

首页「开始生成」分别提交本次已就绪的项目，不会把不同文件夹的素材混合出片。成片库按生成项目分组，可筛选项目、全选单个项目后导出；切换项目筛选时清空旧选择，防止误操作其他项目。没有项目归属的顶层视频显示在「未分类成片」。已有项目的「补传素材」继续添加到所选项目。

## 全部素材参与脚本规划

产品片和门店介绍片都不限制引用原素材的条数，也不限制补充句数或成片时长。整批识别结果统一交给大模型，先逐条整理有效信息，再按主题规划；重复内容择优保留，清晰完整的新信息纳入对应脚本。程序不再按 20 分钟人声拆组后跳过已规划主题，也不再按文字相似度自动删除已选句子。脚本请求不设置应用层输出字数预算，仍受所选模型自身的上下文与输出能力约束；接口超限会报错，不截掉输入素材。新规则在下次重新生成脚本时生效，已有脚本和成片不自动重做。
